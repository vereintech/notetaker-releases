# Notetaker — releases

Download the latest Notetaker for macOS (14.4+, Apple Silicon):
**[Latest release →](https://github.com/vereintech/notetaker-releases/releases/latest)**

1. Open the `.dmg` and drag **Notetaker** into **Applications**.
2. The first time, right-click Notetaker → **Open** → **Open** (the app isn't notarized by Apple yet).
3. After that, updates download and install automatically (or via **Periksa Pembaruan…**).

This repository only hosts release builds and `appcast.xml` for Sparkle updates.
